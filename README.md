# Python Programs Collection

A beginner-friendly collection of Python programs for practicing fundamental programming concepts.

## Programs

### 1. Factorial
Calculates the factorial of a non-negative integer using a loop.

### 2. Fibonacci Sequence
Generates the requested number of terms in the Fibonacci sequence.

### 3. Structure to Dictionary Conversion
Converts matching field names and values into a Python dictionary.

## Requirements

- Python 3

## Run a program

```bash
python factorial.py
python fibonacci.py
python structure_to_dictionary.py
```

## Learning objectives

- Functions and loops
- Conditional statements
- Lists and dictionaries
- Input validation
- Basic exception handling
